# Scoring — Proteg'Enfance — veille externe d'enrichissement (protection de l'enfance)

> Logique générale : `references/scoring-rubric.md`. Règles/environnement : `references/veille-pipeline.md`.

## Objectif & public cible

**Alimenter la plateforme `protegenfance.fr`** : repérer **ailleurs sur le web** des contenus (actualités,
événements, ressources) sur la *protection de l'enfance*, à **relayer ou adapter**. Public cible :
**responsable éditorial / animateur** de Proteg'Enfance. **Ne jamais** remonter le contenu de protegenfance.fr
(domaine exclu).

## Type de contenu (`content_type`) — obligatoire

Classer via `settings.content_type_hints` + la nature de l'URL :
- **evenement** : colloque, assises, journée d'étude, webinaire, rencontres (repérer date/lieu).
- **ressource** : guide, retour d'expérience, étude, rapport, référentiel, fiche pratique, MOOC.
- **actualite** : info datée (réforme, décision, publication, nomination). **Défaut**.

## Actionability = pertinence d'enrichissement

- **3** (exceptionnel) : pile dans un pilier, source crédible, apport net directement relayable.
- **2** : intéressant, à considérer. **1** : contexte marginal. **0** : hors sujet / non crédible / déjà couvert.

## Mots-clés transverses

protection de l'enfance, ASE, aide sociale à l'enfance, mineur, jeune majeur, département, PMI, MECS,
famille d'accueil, assistant familial, placement, mesure éducative, CRIP, information préoccupante.

## Axes (piliers) — mots-clés cœur (score 3)

- **se-reperer** : cadre légal, loi protection de l'enfance, mesure éducative, parcours de l'enfant, acteurs, gouvernance, IP/CRIP.
- **se-former** : métiers du social, formation, recrutement, attractivité, éducateur, assistant familial, VAE, compétences.
- **accueillir** : MECS, maison d'enfants, famille d'accueil, lieu de vie, immobilier social, capacité d'accueil, foyer.
- **accompagner** : sortie de l'ASE, jeunes majeurs, autonomie, insertion, contrat jeune majeur, logement, parcours de sortie.
- **prevenir** : prévention, PMI, prévention précoce, repérage, maltraitance, soutien à la parentalité, prévention spécialisée.
