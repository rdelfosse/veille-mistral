# Scoring — Numérique 360 — veille externe d'enrichissement (numérique des collectivités)

> Logique générale : `references/scoring-rubric.md`. Règles/environnement : `references/veille-pipeline.md`.

## Objectif & public cible

**Alimenter la plateforme `numerique360.banquedesterritoires.fr`** : repérer **ailleurs sur le web** des
contenus (actualités, événements, ressources) sur le *numérique des collectivités*, à **relayer ou adapter**.
Public cible : **responsable éditorial / animateur** de Numérique 360. **Ne pas** remonter le contenu du
sous-domaine (exclu) ; en revanche `banquedesterritoires.fr` (Localtis) reste une source **externe** valable.

## Type de contenu (`content_type`) — obligatoire

Classer via `settings.content_type_hints` + la nature de l'URL :
- **evenement** : colloque, webinaire, salon, journée d'étude, assises (repérer date/lieu).
- **ressource** : guide, retour d'expérience, étude, rapport, fiche pratique, méthodologie, MOOC, référentiel.
- **actualite** : info datée (annonce, décision, publication). **Défaut**.

## Actionability = pertinence d'enrichissement

- **3** (exceptionnel) : pile dans une thématique, source crédible, apport net directement relayable.
- **2** : intéressant, à considérer. **1** : contexte marginal. **0** : hors sujet / non crédible / déjà couvert.

## Mots-clés transverses

numérique, collectivité, territoire, données, data, cybersécurité, IA, inclusion numérique, cloud,
souveraineté numérique, interopérabilité, dématérialisation, GovTech, smart city.

- **transition-eco-energetique** : sobriété numérique, green IT, numérique responsable, data au service du climat, écoconception.
- **attractivite-amenagement** : jumeau numérique, smart city, aménagement numérique, THD/fibre, attractivité territoriale.
- **citoyens-solidarite** : inclusion numérique, médiation numérique, e-inclusion, accès aux droits, illectronisme, aidants numériques.
- **mobilites** : données de mobilité, MaaS, open data transport, capteurs mobilité, mobilité intelligente.
- **gouvernance-socles-tech** : cybersécurité, cloud souverain, interopérabilité, RGPD, open data, socle numérique, France Connect.
- **ia** : intelligence artificielle, IA générative, cas d'usage IA, IA de confiance, Albert, agent conversationnel collectivité.
